# Leaf Me Alone: game design summary for agents

The design workbook at `design/leaf-me-alone-workbook.xlsx` is the source of truth for the game's design. This file is a readable summary of it for agents, because agents read markdown reliably and spreadsheets poorly. When the two disagree, the workbook wins, and this file should be updated to match.

The workbook's own rule applies here too: only items marked Confirmed are canon. Everything else is a working assumption or a proposal. IDs in brackets (GV-, DEC-, BR-, OQ-, BL-, BAL-) refer to rows in the workbook so anything can be traced back.

## Confirmed canon

- **Title and studio.** Leaf Me Alone, by n.I.C.E. Games. [DEC-012, DEC-002]
- **Pitch.** A multiplayer comedy where undocumented workers take impossible leaf-cleanup jobs, buy better tools, and scramble when a fictional enforcement crew arrives during run events. [GV-01]
- **Format and length.** Multiplayer. A full successful playthrough takes roughly 5 to 10 hours. [DEC-003, DEC-004]
- **Starting point.** Players start together at Homie Depot, a contractor or home-improvement style store. [DEC-005]
- **The truck.** Any truck model uses the Chefty logo. A truck takes a subset of the players to a job lot. [DEC-006, GV-04]
- **The work.** Players rake an absurd, insurmountable quantity of leaves. [DEC-007]
- **Payout.** Pay is based on how much, or what percentage, of the leaves players clean up. The exact split is not decided. [DEC-008]
- **Progression.** Returning to the store gives access to tools that make future cleanup easier. [DEC-009]
- **Tone.** Quippy and funny. Relevant, but not intended as a party-political statement. [DEC-011, DEC-014]
- **The threat.** Certain conditions trigger run events in which a fictional enforcement crew tries to capture players. The crew is never called ICE in player-facing content, and its final name is not decided. [GV-07, GV-11, DEC-015]
- **Capture.** Captured players enter Border Return Mode, a lane-crossing arcade mode where they cross the border back to the yard. [DEC-016]
- **Capture cohort.** Everyone captured in the same group enters the same Border Return instance and crosses at the same time. [DEC-017, GV-14]
- **The van.** The van visibly contains exactly as many players as were captured. [DEC-018]
- **Border Return failure.** Failing throws the player back over the border comically to retry, with no credit penalty. [DEC-019, BAL-28]

## Working assumptions (tunable, not canon)

These come from the workbook's Balance Lab and are mirrored in `core/balance.gd`, which is generated by `design/export_balance.py`. Never hardcode these numbers in gameplay code. Reference the `Balance` constant instead, so changing the workbook and re-running the script changes the game.

- Eight lots, with leaf volume growing 65% per lot from 8,000 leaf units. [BAL-08, BAL-09, BAL-18]
- A leaf unit is an abstract tuning unit, not a literal count of rendered leaves.
- Four players travel on the truck. [BAL-05]
- Base cleanup rate of 120 leaf units per minute per player, with tools multiplying throughput by 1.35 per tier. [BAL-07, BAL-12]
- Contribution weights of 70% leaves cleared, 15% rescues, and 15% objectives or support. [BAL-20 to BAL-22]
- Run events start at a 10% chance per lot, rising 5% per tier, capped at 65%, with a 12-minute cooldown. [BAL-14 to BAL-16, BAL-25]
- Border Return runs about 3 minutes. [BAL-17]
- 45-minute play sessions. [BAL-04]

The workbook's own Progression sheet flags lots 4 through 8 as longer than one 45-minute session, with lot 8 at roughly 100 minutes. Either the curve changes or saves have to capture a lot in progress. Treat that as unresolved.

## Open questions that affect code

Until these are decided, build the behavior so the answer can change without a rewrite: a tunable constant, a flag, or a small strategy object. When you implement around one of them, name the OQ id in a code comment.

| ID | Question | How code should handle it for now |
| --- | --- | --- |
| OQ-001 | Camera perspective | Decided 2026-10-21: first person, with your own arms in view (see Developer notes). The over-the-shoulder camera stays on its toggle for debugging |
| OQ-002, OQ-003 | Who boards the truck, and what do non-travelers do | Truck capacity comes from `Balance`. Boarding rule is one function that is easy to replace. Non-travelers stay in the store zone |
| OQ-004 | What counts as a leaf being cleaned | The leaf field supports both moving leaves (raking into piles) and removing them (bagging). The definition of "cleaned" is one function |
| OQ-005, OQ-006 | Individual, shared, or hybrid payout; whether support counts | Payout is computed in one host-side function from per-player stats, using the `Balance` weights |
| OQ-009, OQ-010 | Run event triggers, warnings, and counterplay | Decided 2026-10-21: the crew's heat drives the rolls and the crew's size (see Developer notes); the progress rule still gates the first roll. Counterplay: hide spots, piles, and throwing things at them |
| OQ-011 | Does a Border Return miss reset one player or the whole cohort | Flag, default individual |
| OQ-014 | One session or many | Campaign saves between jobs. Mid-job saves are not built until decided |
| OQ-016 | Player count | Built and tested for up to 8 (`Constants.MAX_PLAYERS`) |
| OQ-022 | Border Return length and difficulty scaling | Hazard timelines are data, scaled by a difficulty value |
| OQ-023 | What happens on the lot while a cohort is in Border Return | The lot keeps running. Contribution keeps accruing only for players on the lot |

| OQ-027 | Do players finish Border Return individually or as a group | Flag, default individual |

## Developer notes

- **2026-10-12.** The store is called Homie Depot.
- **2026-10-12.** Any truck model will be called Chefty logo.
- **2026-10-12.** A wheelbarrow holds 4 leaf bags. One shop upgrade raises that to 8. Chefty holds 50. Throw the wheelbarrow at Chefty to move the bags into the truck. These sizes are not in the workbook yet.

- **2026-10-19.** The audio is goofy, not realistic, in the spirit of Schedule I. Characters never speak real words: they make silly noises and babble.
- **2026-10-19.** Each job has exactly one rake. Raking needs it; without it you rake with your hands, which is goofy and barely works. Raking leaves into a bigger pile makes a fuller bag, and each bag has a dollar value from the leaves inside.
- **2026-10-19.** The homeowner stands beside the truck. Talking to them gets a reaction that depends on randomness and on how long the job took (for example "Took long enough eh?" or "You did a great job, here's a tip!"), shown as a caption over their head with a goofy noise. They hold out the cash, and someone has to grab it. Pay is the delivered bags' value times the mood. The mood rules, multipliers, and patience time are stand-ins in `core/constants.gd` until the workbook has them; the lines were finished on 2026-11-01 (see "the cast").
- **2026-10-20.** Every item has a weight. Heavier items slow you down while you carry them and fly less far when thrown. A thrown item that hits a person (a player or a passerby) reacts by weight: a light one makes them flinch, a medium one staggers and shoves them, a heavy one knocks them flat with stars. Weights and tiers are stand-ins in `core/constants.gd` until the workbook has them.
- **2026-10-20.** The streets have people walking on them, and the world has lived-in details: grass, sidewalk chalk, spray-paint tags, sticky notes, and posters. None of them have words yet.
- **2026-10-20.** Tools unlock tasks. Buying a tool at Homie Depot (leaf blower, lawn mower, ladder, hose, pressure washer, hedge trimmer, paint roller) unlocks the work it does, and everyone's tools come along to every job. Taylan named mowing, blowing, gutters, windows, and the driveway; picking up litter, pulling weeds, trimming hedges, and painting the fence were added to the list. Every job is a different, generated yard, and the homeowner asks for a different mix of work, sometimes something the crew has no tool for yet. Pay is the bags plus each task's pay by how much got done, times the mood. Prices, pay, and rates are stand-ins in `core/constants.gd`.
- **2026-10-20.** You hold one thing at a time. Hold G to wind up a throw (a bar shows how hard), release to throw, tap G to set it down. Hold on more than 5 seconds and you strain; at 7 you faint for a moment and drop it. A big throw comes with a grunt. A job asks for three things: the leaves plus two more.
- **2026-10-20.** Jobs make physical sense. Chefty parks at the curb, not on the driveway, and nothing walks through it; no leaves fall on the driveway. The ladder has to be set up against a gutter and climbed; gutters are scooped from the top, faster with the leaf blower. The hose has to be hooked to Chefty's tank (free), the house's spigot (the homeowner bills you), or a fire hydrant (way too much pressure: it drags and lifts whoever holds on). Walk farther than the hose reaches and it snaps loose and whips, knocking out whoever it hits. Water flies in a real arc and only cleans what it reaches. The pressure washer has a tank that runs dry and refills at any water source. (Taylan wrote "fire extinguisher"; the hydrant is the reading taken.)
- **2026-10-20.** You can climb off the ladder onto the roof and walk on it; the roof's leaves are a task too. A set-up ladder comes back down with F. Fall from high enough and you bounce, get knocked out for a moment, and limp with a bandaged leg for a while (players aren't told how long). The mower has to be pull-started, and the paint roller has to be dipped in the paint bucket and runs dry.
- **2026-10-20.** A running mower chews up whatever it rolls over: leaves turn to confetti (gone, unpaid), litter gets flung across the yard, a hose gets cut (the homeowner bills for a new one), a leaf bag bursts, the gnome grinds and stalls the mower (billed), and feet get cut, or come clean off and fly away, leaving the victim hopping until the job's paid. Medical bills come off the pay. Comical, never gory.
- **2026-10-20.** Sound pass approved by Taylan: tools make their running noise for everyone nearby (mower engine, blower, hose, pressure washer, trimmer, roller), footsteps sound different in leaves, on grass, and on pavement, and the neighborhood has a breeze, birds, a dog, and passing cars. A laid-back music loop plays; M turns it off and on.
- **2026-10-20.** Job board approved by Taylan: a cork board by the checkout at Homie Depot shows three job offers, each a different yard (small, regular, or big) with its house number, the work the homeowner wants, and what that work pays (leaves pay by the bag on top). Anyone can pick one until Chefty sets off; new offers go up when the crew is back. A big yard asks for one more job. Sizes and chances are stand-ins in `core/constants.gd`.
- **2026-10-21.** The enforcement crew is the NICE BOYS (Taylan). Player-facing text says "the NICE BOYS"; the workbook's DEC-015 rule (never "ICE") still stands for everything else.
- **2026-10-21.** The camera is first person, and you see your own arms: they reach for whatever you hold, swing the rake, pump as you walk, wind up over your shoulder for a throw and shake when you strain, go hand over hand up a ladder, and flop when you're knocked out (OQ-001 closed, Taylan: "always funny").
- **2026-10-21.** The homeowner's lines were written to be funny (Taylan asked): six per mood, plus lines about whatever the crew broke that come up most of the time when there's a bill. They're in `ui/strings.gd` and are not in the workbook yet.
- **2026-10-21.** Heat (Taylan: "why not both", docs/FUN.md). Running tools, the hydrant, bills for what got broken, and bonked passersby raise the crew's heat; it cools while the job is quiet and a lot when a job is paid. Heat sets how often the NICE BOYS roll and how many come (up to three), and a raid drops it back down. A meter on the HUD shows it, with a nudge at 50 and 80.
- **2026-10-21.** Gags, same day: a running mower let go of drives off on its own, mowing whatever it meets, until it stalls or someone grabs it. Anything thrown hard at a set-up ladder (or a mower into it) knocks it down with whoever's on it. A big enough raked pile can be dived into with E: you're hidden unless a NICE BOY watched you go in, and a rake or a mower through the pile turns you out. Thrown things stun the NICE BOYS by weight tier, at a cost in heat. Paint from the roller and water from the hose or washer land on other players (paint sticks until it's hosed off; water makes you slip for a moment) and on passersby, who get mad.
- **2026-10-21.** Brawling (Taylan: punch, grab, "a silly wind up punch"). With empty hands, hold left click to wind up a punch: the arm windmills, the longer the harder (light, medium, heavy by how long), and winding past three seconds spins you out onto the ground. Release to swing at whoever's in front: players, passersby (heat), or the NICE BOYS (counterplay, more heat). Left click with something heavy in hand whacks with it, as hard as it's heavy. E by another player grabs them: they hang kicking in front of you and can mash keys to wriggle free (which knocks you back); E sets them down, G winds up and throws them, and a thrown player takes down whoever they fly into and dives into a pile if they land in one.
- **2026-10-20.** Yard size changes the yard: small yards have a bungalow, few trees, and fewer leaves; big yards have a two-story house, more trees, thicker leaves, and an above-ground pool with leaves floating in it to scoop out by hand. When the homeowner pays, they rate the job 1 to 5 stars by their mood. The crew's rating is the average of the last ten, shows on the job board, and a rating above three stars brings more big yards.

- **2026-11-01.** Taylan's direction: Schedule I is the model for the look and the loop, the town is persistent, four players, early access (no ending yet), and agents have creative freedom. `docs/SPINE.md` is the design that follows from it. Decided by the agent under that freedom, and canon until changed: the work day runs 7 AM to 2 AM with quiet hours from 9 PM (more pay, more heat); the crew sleeps on cots at the **crew camp** by Homie Depot's side wall, and sleeping banks the day's XP; the crew shares one rank, eight ranks of five tiers (Rake Rookie, Leaf Grunt, Bag Hauler, Mulch Mule, Hedge Hog, Turf Boss, Lawn Lord, Yard Baron) then the endless **The Lawnfather**, each tier unlocking something (`core/ranks.gd`); the town's six neighborhoods are **Maple Row, Dandelion Acres, Birchwood Commons, Oak Hollow, Lakeside, Mansion Hill** (`net/town/neighborhoods.gd`); homeowners have names, personalities, standards, budgets, and favorite work, and refer neighbors when they're happy; the Homie Depot clerk is **Marty**; the rival outfit that arrives at Mulch Mule III is **TurfMasters™**. The crew phone (Tab) holds texts, clients, the map, and the crew's rank.

- **2026-11-01, the guardrail in code** (agent, under creative freedom). The humor guardrail is now one checked list, `net/dev/guardrail.gd`, run over every text table by `tools/guardrail_check.gd` in CI (the `guardrail` step) and used by the string audits in the cast and art tests. What it holds the line on:
  - **No real agency, and no police.** No ICE, CBP, DHS, USCIS, FBI, DEA, ATF, IRS, INS or TSA, no "immigration", "homeland", "customs" or "border patrol", no cops, sheriffs or paddy wagons. ICE is checked as the capitalized acronym, so winter's *ice on the driveway* is fine. **N.I.C.E.** is banned: the NICE BOYS never get dotted into an acronym. "Ice cream" is out too, because the pun is the obvious trap.
  - **No immigration status, ever.** Not "illegal", "undocumented", "alien", "deport", "visa", "green card", "citizen", "papers, please", "the border". Bureaucracy jokes say **unpermitted**: an *unpermitted wheelbarrow* is funnier anyway, and it's about the paperwork, not the person.
  - **Nobody's origin or voice.** No nationalities or ethnicities named in jokes, no "go back where you came from", "speak English" or "funny accent", no mock-Spanish (amigo, señor, no habla, no problemo) or mock-accent spelling, and no stereotype props (sombreros, piñatas, siestas, maracas, mariachis). Slurs are blocked by stem, including the ones that hide in everyday phrases: the crew leaves a yard **spotless**, not "spic and span", and a bad deal is a **rip-off**, not "gypped".
  - **NICE BOYS is written in caps.** "Nice Boys" fails; lowercase "nice boys" is allowed for the pun ("Nice work, nice boys"). Two homeowner lines that said "Nice Boys" were fixed.
  - Border Return keeps its name: it's a game zone, and the check only blocks "the border" bits, not the word.
  - A false positive is fixed by rewording the line, never by loosening a pattern. A new risk gets a pattern and a sample line in `SHOULD_HIT`.

## Rules for agents working on content

- Agents may create canon (Taylan, 2026-11-01): names, lore, client characters, and dialogue. Record each one in this file's developer notes in the same commit, so the next agent uses it instead of inventing another. The store name Homie Depot, the Chefty truck logo, and the enforcement crew's name, the NICE BOYS, are Taylan's and stay.
- Never use "ICE" or any real agency's name in player-facing text, art, or audio. [DEC-015]
- Player-facing text lives in one strings file so it can be reviewed in one place. The quips in the workbook's Humor & Quips sheet are drafts. Use them only when the developer asks, and keep their Q ids next to them.
- The workbook proposes a humor guardrail: punch up at impossible work, precarious systems, and enforcement bureaucracy, not at immigrants, ethnicity, nationality, or accents. [GV-13] Follow it for anything you draft, and flag anything that might cross it. Every player-facing string must pass `net/dev/guardrail.gd` (`Guardrail.check(text)` returns the hits); `tools/guardrail_check.gd` sweeps the text tables and fails CI on any hit. A new table of player-facing text goes in its `SOURCES` list.
- The design backlog (BL-001 to BL-012) is mapped to milestones in `docs/PLAN.md`.
